DOEN HUSTLE HUB — WEBSITE VERSION 1

FILES
- index.html: webpage structure
- style.css: colors, layout, responsiveness, visual styling
- script.js: event information, games, contact numbers, Google Maps search, WhatsApp buttons


OPEN THE WEBSITE
1. Extract all three files into one folder on your computer.
2. Double-click index.html.
3. It should open in your default browser. Internet is only needed for the Google Fonts styling and WhatsApp/Maps links.


EDIT FOR A FUTURE EVENT
Open script.js in Notepad. At the top, find the eventInfo object. Change the event name, date, time, venue, prices, note, contact numbers, and mapSearch. Save the file, then refresh the webpage in your browser.


EDIT THE ACTIVITIES
In script.js, find the activities array. Each entry has an icon, title, and description. Copy an entry to add a new game; edit or delete entries as needed.


WHATSAPP
The contact buttons create WhatsApp messages to the two numbers from the poster. Confirm that the numbers are correct and WhatsApp-enabled before sharing this website publicly.


NOTE
This is a static website. It does not yet have an admin login, online ticket payment, or a booking database. Those can be added in a later version.
